# Бариста Кінця Світу

Low-poly RPG про бариста-кур'єра у світі, що розвалився від вигорання.

## Грати з друзями
```
python3 start.py              # порт 7777, сервер + тунель + монітор
python3 start.py --port 8088  # інший порт
python3 start.py --tunnel none
```
Для публічного посилання встанови **cloudflared** (рекомендовано, без реєстрації) або **ngrok**.
Без них start.py спробує `ssh localhost.run`, а якщо нічого немає — працюватиме в локальній мережі.
Друзі просто відкривають посилання з монітора в браузері.

У грі: Enter — чат, `/wave /dance /cheer /sit` — емоції, біля іншого гравця дія — пригостити кавою.

## Розробка
- Зібрати: `npm i && npm run build` → `dist/index.html`
- Тести: `npm test` (гра) і `npm run test:net` (сервер + 2 гравці)
- Для ШІ-агента: `AGENT_INSTRUCTIONS.md`
