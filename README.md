# Бариста Кінця Світу

Low-poly RPG про бариста-кур'єра у світі, що розвалився від вигорання.

## Грати з друзями
```
python3 start.py              # порт 7777, сервер + тунель + монітор
python3 start.py --port 8088  # інший порт
python3 start.py --tunnel none
```
Для публічного посилання встанови **cloudflared** (рекомендовано, без реєстрації) або **ngrok**.
Без них start.py спробує `ssh localhost.run`, а якщо нічого немає — працюватиме в локальній мережі.
Друзі просто відкривають посилання з монітора в браузері.

### Акаунти
Онлайн гра вимагає акаунт (логін + пароль). Прогрес зберігається на сервері в `saves/`,
тому **не губиться, коли тунель видає нове посилання** — просто увійди знову.
- Перший зареєстрований акаунт — адміністратор (вкладка 🛡️ Адмін у меню: бан/розбан, кік, права, видалення, оголошення).
- `python3 start.py --admin Логін` — видати адмінку, `python3 start.py --unban Логін` — розбанити з консолі.
- Видалити свій акаунт: на титульному екрані або в ⚙️ Налаштуваннях (потрібен пароль).

### Керування
WASD — рух · ЛКМ — удар · Q / ПКМ — кинути напій · **E — інвентар** · **F — дія** (бар, скрині, візки, вентилятори, підняти моба) ·
Enter — чат, `/wave /dance /cheer /sit` — емоції, біля іншого гравця F — пригостити кавою.
У вкладці 👥 Онлайн видно, що робить кожен гравець (атакує, варить, рибалить…).
