# Аддони

Нова локація, режим, предмет чи механіка приходить **одним файлом-аддоном**.
Не треба перезбирати гру й заміняти весь архів.

## Як поставити аддон
1. Кинь файл `щось.js` у цю папку `addons/`, поруч зі `start.py`.
   Аддон із картинками чи звуками — це папка `addons/назва/` з файлом `addon.js` усередині.
2. Онови сторінку гри (F5). Перезапускати сервер не треба.
3. Перевір у ⚙️ Налаштування → 🧩 Аддони, що він завантажився без помилки.

- **Вимкнути** аддон: перейменуй його так, щоб назва починалась з `_` (наприклад, `_disco.js`), або видали файл.
- Аддони вантажаться за алфавітом.
- Друзі отримують аддони автоматично, бо гра йде з твого сервера.
- Аддони працюють тільки коли гра відкрита через `start.py`. Звичайне відкриття `dist/index.html` їх не бачить.
- Аддон, що зламався, не валить гру: він просто вимикається, а помилку видно в налаштуваннях.

Приклад лежить у `_examples/disco_island.js`: острів із танцполом, клавіша G, вкладка в меню, кнопка «покликати всіх».
Скопіюй його сюди без `_examples`, і він запрацює.

## Для розробника (і ШІ-агента): як писати аддон
Аддон — це звичайний JS. Він бачить усі змінні й функції гри (`P`, `pl`, `MON`, `ISL`, `BASE`, `DRINK`, `QUESTS`,
`scene`, `mesh`, `mat`, `toast`, `spawnMonster`, `addProp`, `addLampGlow`…) і має API `Addon`:

```js
const A = Addon.info({ name: 'Назва', version: '1.0', desc: 'Що робить' });

// Контент додаємо одразу (до побудови світу):
A.island({ id: 'myisl', n: 'Мій острів', sub: 'підпис', x: -20, z: 46, r: 8, top: '#C9B3F5', rock: '#8C84C6', tier: 1.5, spawn: [['office', 3]] }, 'park'); // + міст до park
A.bridge('myisl', 'hub');
Object.assign(BASE, { myitem: { n: 'Річ', ic: '🎸', slot: 'hand', style: 'swing', dmg: 8, spd: 1.2, rng: 2, rad: 1.2, crit: .1, kb: 8, dur: 100, wt: 1, use: .15, d: 'Опис' } });
QUESTS.splice(QUESTS.length - 1, 0, { n: 'Квест', d: 'Опис', ev: 'calm', need: 5, target: [-20, 46], rw: { xp: 200, coins: 50 } });

A.on('world', () => { /* будівлі: scene.add(...). Те, що рухається — scene.add(A.dynamic(obj)) */ });
A.on('start', () => { /* гравець зайшов у гру; P уже завантажено */ });
A.on('tick', dt => { /* кожен кадр під час гри */ });

A.key('KeyG', () => { /* клавіша */ });        // return false — клавіша піде грі як звичайно (напр. Q)
A.tab('mytab', '🎸 Моє', () => '<h3>HTML вкладки</h3>', e => { /* кліки у вкладці */ });

A.send('type', { any: 'json' });                 // усім іншим гравцям онлайн (до 4 КБ)
A.onNet('type', (data, from) => { /* from.name, from.id */ });
A.data().score = 5;                               // зберігається в прогресі акаунта
A.mode({ id: 'mymode', ic: '🎯', n: 'Мій режим', sub: 'опис', go: () => {/* перенести гравця */}, here: () => false });   // режим у меню паузи (Esc)
```

Правила:
- Острови, мости, предмети, напої й квести додавай у верхній частині файлу, а не в `on('start')`.
- Не змінюй файли гри з аддона. Тільки додавай і підписуйся на події.
- Ідентифікатори (острови, предмети) роби унікальними, з префіксом аддона.
- Тексти пиши українською, у пастельному стилі гри.
